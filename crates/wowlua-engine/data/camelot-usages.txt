# no arguments, numbers, strings, tables; tests/client/forever-camelot-fullprobe.lua).
# `name<TAB>checks<TAB>message`: a call whose arguments a check refuses
# raises the message (Lua's `luaL_error`: the caller's position first).
# Checks by argument: number (a number or a numeric string), index (one
# above 0), nonneg (0 or above), nonzero (any number but 0), string (a
# string or a number), strictstr (a string), table, required (any value
# but nil), guid (a GUID or 0), any; `?` lets it be nil or left out;
# never (every value the probe tried refused); companion ("CRITTER" or
# "MOUNT", unverified); optnumber (a number or none, refused with Lua's own
# "number expected": message `-`); questitem ("required", "choice" or

# Each check is the loosest that explains every answer, a usage's named
# arguments preferring any value but nil: untried values are unverified.
